## Limits that are not hidden

* No project has an external security audit.
* No project is positioned for real funds or Mainnet use.
* Sideband has not completed a phone or Bluetooth hardware test.
* Torrent hosted wallet flow must be evaluated only against the evidence recorded in its repository.
* Unbound mobile can build an APK but has not been validated on a physical phone.
* Free-tier backend services may cold start.

Treat linked records as evidence of exactly what was tested, not as a blanket production claim.
