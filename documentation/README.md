# Stellar Wave portfolio

This is the reviewer and contributor entry point for three public Stellar Testnet projects: **Sideband**, **Torrent**, and **Unbound**.

{% hint style="warning" %}
All three projects are Testnet prototypes. They use synthetic or throwaway assets, have not received an external security audit, and are not suitable for real funds.
{% endhint %}

## Reviewer path

1. Read the product overview for the project you are reviewing.
2. Read architecture and repository relationships.
3. Check the security and contribution controls.
4. Use Testnet evidence and known limits before treating any flow as proven.
5. Find scoped, labeled work in each repository's Stellar Wave issues.

The GitHub repositories are canonical for implementation documentation. This GitBook provides cross-repository review context.
